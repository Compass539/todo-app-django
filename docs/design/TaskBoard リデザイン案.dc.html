# Handoff: TaskBoard リデザイン（採用案 1d） ## Overview 既存の TaskBoard（Django REST Framework + React/Tailwind）の UI を、Organic デザインシステム（クリーム地＋テラコッタ／セージ、Caprasimo + Figtree、大きな角丸とピル形状）で刷新する。採用案は **1d：細い左レール＋期限グルーピング／高密度**。 対象範囲： 1. タスク一覧（デスクトップ） 2. タスク追加フォーム展開時 3. ログイン／新規登録 4. スマホ表示 5. カレンダー画面（新規機能。README「今後の展望」由来） 機能仕様は現行のまま（JWT 認証、カテゴリ、期限、インライン編集、検索、期限切れ警告、Discord 通知）。変更点は情報構造とビジュアル。 ## About the Design Files このバンドルの HTML ファイルは **デザインリファレンス**（見た目と挙動を示すプロトタイプ）であり、そのまま本番コードとして貼り付けるものではない。既存の `todo-react`（React 19 + Vite + Tailwind CSS v4）環境の作法に沿って作り直すこと。Tailwind を使う場合、下記トークンを `@theme` のカスタムカラー／スペーシングとして定義し、任意値（`bg-[#c67139]` 等）の直書きは避ける。 ## Fidelity **High-fidelity（hifi）**。色・タイポ・余白・角丸・影は下記の値で確定。ピクセル忠実に再現してよい。 ## 情報構造の変更点（現行 → 1d） | | 現行 | 1d | | --- | --- | --- | | ナビ | 幅 224px の白いサイドバー（カテゴリ・サマリー・ログアウト） | 幅 80px の濃色レール（アイコンのみ、44px 円形） | | 一覧の並び | 選択カテゴリのタスクを1列 | 選択カテゴリ内を **期限切れ / 今週 / 完了** でグルーピング | | 行 | カード（角丸12px、左に6pxバー、期限バッジは下段） | 高さ 44px のピル行（丸チェック・タイトル・右端に日付） | | サマリー | サイドバー内のテキスト3行 | 右カラムに進捗リング（conic-gradient）＋サマリー＋通知説明 | | 期限切れ表現 | 赤（red-100/red-500） | テラコッタ ramp（accent-200 地／accent-900 文字） | | 完了表現 | opacity .6 ＋ 取り消し線 | セージ ramp（accent-2-100 地／accent-2-800 文字）＋ 取り消し線 | 赤・緑は使わない。期限切れ＝テラコッタ、完了＝セージ、通常＝ニュートラルの3系統で表す。 ## Design Tokens `organic-styles.css`（同梱、design system の唯一のスタイルシート）が正。抜粋： **色** -
